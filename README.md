# 兆辉防腐 · 全网获客作战台

面向钢衬四氟、钢衬PE/PO储罐、反应釜、塔器、管道等衬氟设备企业的全网内容运营与获客管理网页软件，把短视频、图文、搜索询盘、私域承接、线索跟进和数据复盘放在一个工作台里。

## 功能模块

- 全局驾驶舱：六层获客涂层、平台火力表、获客漏斗、今日任务
- 平台矩阵：抖音、快手、视频号、小红书、B站、公众号、知乎、百家号、头条、官网、1688、企业微信、朋友圈的定位与发布节奏
- 内容工厂：按钢衬四氟、板衬四氟工艺、钢衬PE/PO、衬氟管道/塔器、旧设备翻新等场景生成口播脚本、文章大纲、标题、文案、关键词和转化引导；内置 30 条衬氟设备行业选题
- DeepSeek 增强生成：接入 DeepSeek 后可用 AI 生成更贴合工况的内容，参数在「参数设置」中配置
- 全网实时情报：自动搜索钢衬四氟、PE/PO、反应釜、塔器、管道等关键词，抓取招标、采购和行业动态，并用 DeepSeek 生成情报摘要和跟进建议
- 排期作战台：周视图排期、手动添加任务、一键生成 21 条周排期
- 线索池：全平台线索集中跟进、阶段推进、下次跟进日期、私域承接模板
- 素材软件库：把已有的报价系统、案例库、素材库、后台工具接入获客链路
- 数据复盘：按平台记录曝光、点击、粉丝、留言、留资和成交额，自动计算合计
- 参数设置：公司简称、主营产品、电话、企业微信、官网可自定义

## 使用方式

直接用浏览器打开 `index.html` 即可使用，无需安装依赖。

所有新增任务、线索、软件和复盘数据会保存在当前浏览器的本地存储中。需要恢复初始示例数据时，在「参数设置」里点击「重置示例数据」。

## DeepSeek 配置

在「参数设置」中填写：

- DeepSeek API Key
- API 地址，默认 `https://api.deepseek.com`
- 模型，默认 `deepseek-chat`

部署在阿里云服务器时，系统会把本机已保存的 DeepSeek Key 写入服务器配置，网页端通过 `/api/deepseek` 自动调用，不需要把 Key 写进前端代码。

## 实时情报

「实时情报」页面支持：

- 自定义监测关键词，默认覆盖钢衬四氟、钢衬PE/PO、板衬四氟、衬氟管道等
- 一键刷新全网搜索，按相关度标记高相关线索
- 每 30 分钟自动刷新
- 用 DeepSeek 对最新结果生成摘要和跟进建议

## 部署方式

这是一个纯静态网页，包含 `index.html`、`styles.css`、`app.js`，可以整体上传到任意静态网站空间：

- 宝塔面板 / Nginx 静态站点
- GitHub Pages / Vercel / Netlify
- 公司官网子目录，例如 `https://www.example.com/zhaohui-ops/`

如果需要在 GitHub 手动上传，可打开目标仓库后点击「Add file -> Upload files」，把这 4 个文件拖进去提交即可。

## 后续建议

1. 在「参数设置」中填写真实公司、产品和联系方式
2. 把已有的软件链接接入「素材软件库」
